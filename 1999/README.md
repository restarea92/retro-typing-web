## 실행 제한

`app.js`와 다른 모듈에는 제외된 자료에 대한 정적 import가 남아 있습니다. 이 상태의 `index.html`을 열면 누락 모듈 때문에 실행되지 않습니다. 필요한 파일과 데이터 형태는 `ASSETS-NOT-INCLUDED.md`를 참고하세요.

워밍업 시계 표시에는 추가 글리프가 있는 호환 폰트가 필요합니다. 작성한 폰트 처리·검사 도구만 공개하며, 원본 실행파일·기존 폰트·생성 폰트는 공개하지 않습니다. 도구는 입력 파일을 자동으로 내려받거나 실행하지 않습니다. 자료의 적법한 사용 여부는 별도로 확인해야 합니다.

## 검증 범위와 남은 차이

공개 검사는 원본 자료 없이 실행 가능한 테스트와 소스 검사입니다. 리소스 의존 사례는 기본 실행에서 명시적으로 건너뜁니다. 자세한 수치와 선택 실행 방법은 `TESTING.md`에 있습니다.

수정 후보에서는 완료 대화상자, 워밍업 표적 지우기·정렬, 시계에 따른 키 표시, 별도로 유지되는 낱말/짧은 글 최고 속도, 그래프 눈금과 테두리의 소스 동작을 보완했습니다. 이전 버전에서 확인한 긴 실행 경로를 모든 후속 CSS 수정에서 다시 실행한 것으로 합산하지 않습니다.

- 인접한 지표 패널과 바깥 그래프 테두리에는 원본과 다른 픽셀이 남아 있습니다. 전체 패널·전체 화면 일치를 주장하지 않습니다.
- 완료 대화상자가 가린 키의 정리 상태는 소스/DOM 검사 범위이며 원본 화면에서 직접 관찰한 것으로 주장하지 않습니다.
- 원본의 정답 0개 상황에서 초기화되지 않은 값이 표시되더라도 웹은 이를 하드코딩하지 않고 0%를 표시합니다.
- 시계에 의존하는 워밍업 잔상은 같은 시간 조건이 필요하며, 임의의 캡처를 고정해 재현하지 않습니다.
- 브라우저 난수 초기값·오디오·입력기·키 이벤트 전달은 DOS 환경과 다를 수 있습니다. 실제 iOS 입력은 미검증입니다.
- 게임 단계 소스 테스트는 모든 게임 단계의 실제 원본·브라우저 플레이를 검증한 것이 아닙니다.
