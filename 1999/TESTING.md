# 공개 테스트 범위

2026-10-22 최종 테두리 수정 후보의 공개용 사본: **총 240개, 188개 통과, 52개 명시적 건너뜀, 실패 0개**. 건너뛴 항목은 통과로 집계하지 않습니다. 이 결과는 별도의 비공개 전체 QA 수치와 다릅니다.

## 기본 실행

저장소 루트의 `npm test`는 Node.js 20 이상에서 패키지 설치 없이 실행됩니다.

통과한 188개:

- 루트 기본 검사 7개.
- 기존에 선별한 독립 단위 테스트 91개: 점수·세션·저장·시간·설정·진행·텍스트 처리·게임 엔진.
- 게임 단계 엔진 사례 89개. 합성 ASCII 문자열 `w00`~`w59`, `bonus`를 사용하고 실제 tick/hit 경로로 단계 경계를 검사합니다.
- 실제 실행에서 얻은 수치만 보관한 기록 재생 사례 1개. 원본 문장·폰트·캡처·개인 기록은 포함하지 않습니다. 경과 BIOS tick은 소스 공식과 관찰 수치에 맞춘 재구성이며 직접 읽은 메모리 값이 아닙니다.

명시적으로 건너뛴 52개:

- 게임 DOM 시뮬레이션 6개.
- 워밍업 시계 표시 단위 8개, 시계 통합 4개, 행 전환 2개.
- 최고 속도 유지 7개, 완료 전환 14개.
- 모달·테두리·표시 CSS/DOM 11개. 이 중 원본 내장 제목 이미지를 검사하는 1개는 공개본에서 이미지를 제거했으므로 선택 실행에서도 계속 건너뜁니다.

위 검사에는 작은 상태·시간 고정값과 일부 축소된 완료 할당량을 사용하는 사례가 있습니다. 이런 소스/DOM 경계 검사를 실제 장시간 입력이나 원본 화면 대조로 간주하지 않습니다.

## 선택 실행: 리소스 의존 검사

호환 리소스를 로컬에 제공하고 `npm install`로 LinkeDOM 0.18.14를 준비한 뒤 `npm run test:resource-runtime`을 실행합니다. 필요한 자료가 없으면 명확한 오류로 종료하며 자동 다운로드하지 않습니다.

선택 명령은 게임 95개와 위에 보관한 워밍업·최고 속도·완료·표시 검사 및 기록 재생을 실행 대상으로 삼습니다. 제목 이미지 검사 1개는 의도적으로 제외됩니다. 공개 사본에 원본 자료를 다시 넣어 이 선택 실행을 재검증하지 않았으며, 통과를 주장하지 않습니다. 실제 브라우저·운영체제 키 입력·오디오·픽셀 일치 테스트도 아닙니다.

## 공개 소스 검사와 폰트 도구

- `npm run verify`는 Node.js 20 이상과 Python 3으로 공개 범위, 비밀정보 패턴, JS/Python 구문 및 매니페스트 해시를 검사합니다. 제외 리소스를 넣은 실행용 사본에서는 의도적으로 실패합니다.
- `qa/extend-raw-ank-font.py`, `qa/test-raw-ank-font.py`는 직접 작성한 선택 도구입니다. Python 3과 fontTools 4.61.1, 사용자가 적법하게 제공한 원본 실행파일 및 폰트가 필요합니다. 공개 검증에서는 구문만 검사했으며 폰트 추출·검증을 실행하지 않았습니다.
- 생성한 폰트와 상세 출력 자료는 공개 저장소에 올리지 마세요. 도구는 원본 실행파일을 실행하거나 내려받지 않습니다.

## 보관 및 수정 내역

- 추가 테스트·도구의 원본/공개 사본 해시와 수정 범위는 `TEST-SOURCE-MANIFEST.json`에 있습니다.
- 리소스 의존 import를 조건부로 바꾸고 공통 skip 래퍼를 사용했습니다. 검사 본문은 유지하고, 원본 제목 이미지 사례는 명시적 제외로 남겼습니다.
- 기존 게임 단계 테스트의 제공된 소스 SHA-256: `beb68b7dfd6ae8ef5319acfca7fa5d51c7858ed18dce954a8fb9d2a8ee0fbd3b`. 공개 사본은 DOM 6개에 조건부 import/skip을 추가했습니다.
- DOM 도구는 일반 패키지 import `linkedom`을 사용합니다.
- 비공개 보고서, 원본 캡처, 원본 내용의 golden fixture는 포함하지 않습니다. 수치만 있는 QA fixture는 예외적으로 포함하며 `evidenceQualification`에 한계를 적었습니다.
