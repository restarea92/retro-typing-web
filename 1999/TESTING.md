# 공개 테스트 범위

2026-10-22 공개용 사본 검증: 총 193개 중 187개 통과, 6개 명시적 건너뜀, 실패 0개. 건너뛴 6개는 아래의 원본 자료 의존 DOM 시뮬레이션입니다.

## 기본 실행

저장소 루트에서 `npm test`를 실행합니다. Node.js 내장 테스트 러너만 사용하므로 기본 실행에는 패키지 설치가 필요하지 않습니다.

- 루트 기본 검사 7개.
- `tests/`에 선별 보관한 기존 단위 테스트: 점수, 세션, 저장, 시간, 설정, 진행, 글 입력 처리, 게임 엔진 등. 원본 자료나 제외한 모듈이 필요한 테스트는 넣지 않았습니다.
- `qa/game-stage-coverage.test.mjs`: 두 게임의 1~14단계 완료·패배 경계와 특수 효과를 검사하는 결정론적 게임 엔진 사례 89개.
- 같은 파일의 DOM 시뮬레이션 사례 6개는 기본 실행에서 **SKIP**입니다. 원본 자료가 없는 환경에서 실행한 것처럼 통과로 집계하지 않습니다.

게임 단계 테스트의 데이터는 `w00`~`w59`, `bonus` 같은 합성 ASCII 문자열입니다. 원본 사전·문장·스크린샷은 포함하지 않습니다. 엔진 사례는 할당량을 줄여 완료시키지 않고 실제 tick/hit 경로를 순회합니다. 별도의 작은 단위 테스트 중에는 경계 조건을 확인하려고 상태를 직접 설정하는 사례가 있으며, 이를 전체 게임 실행 대조로 간주하지 않습니다.

## 선택 실행: 전체 게임 95개 사례

호환 가능한 외부 리소스를 로컬에 제공하고 `npm install`로 LinkeDOM 0.18.14를 준비한 뒤 `npm run test:resource-runtime`을 실행합니다. 리소스가 없으면 명확한 오류로 종료하며, 자동 다운로드는 하지 않습니다.

이 선택 실행은 게임 엔진 89개와 DOM 시뮬레이션 6개를 모두 포함합니다. 공개 사본을 준비할 때 원본 자료를 다시 채워 넣어 선택 실행을 재검증하지 않았습니다. 실제 브라우저, 운영체제 키 입력, 오디오, 원본 화면과의 픽셀 일치 테스트가 아닙니다.
