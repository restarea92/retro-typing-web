## 선택 실행: 리소스 의존 검사

호환 리소스를 로컬에 제공하고 `npm install`로 LinkeDOM 0.18.14를 준비한 뒤 `npm run test:resource-runtime`을 실행합니다. 필요한 자료가 없으면 명확한 오류로 종료하며 자동 다운로드하지 않습니다.

선택 명령은 기본 명령과 같은 보관된 테스트 파일을 대상으로 하되, 게임·워밍업·최고 속도·완료·표시·키보드/입력 이벤트·자판 전달·메인 포커스·헤더·시작 흐름·기기 입력 정책 사례의 리소스 조건을 활성화합니다. 제목 이미지 검사 1개는 의도적으로 제외됩니다. 공개 사본에 원본 자료를 다시 넣어 이 선택 실행을 재검증하지 않았으며, 통과를 주장하지 않습니다. 실제 브라우저·운영체제 키 입력·오디오·픽셀 일치 테스트도 아닙니다. WebGL 기하/셰이더 코드와 가짜 오디오 객체를 검사하는 사례가 있더라도 실제 GL 컨텍스트·화면·소리·iPhone 터치의 통과를 뜻하지 않습니다.

현재 가상 키보드는 비활성입니다. 보관된 뷰·입력 브리지 테스트는 코드 단위 검사를 위한 것이며 가상 키보드가 현재 앱에서 켜진다는 뜻이 아닙니다. 실제 iPhone/Safari의 화면 키보드·IME·터치 검증으로도 간주하지 않습니다.

새 이벤트 검사의 99/100/2000 ms 경계는 고정된 시계와 직접 구성한 이벤트를 사용합니다. 100 ms는 실제 OS 입력기의 타이밍 보장이 아닌 호환성 기준입니다. 유효한 물리 코드와 비ASCII 글자가 함께 있지만 IME 표시가 없는 모호한 이벤트 분류는 변경하거나 해결했다고 주장하지 않습니다. 별도의 독립 검토 19개는 이 공개 테스트 묶음에 포함하거나 합산하지 않았습니다.

## 공개 소스 검사와 폰트 도구

- `npm run verify`는 Node.js 20 이상과 Python 3으로 공개 범위, 비밀정보 패턴, JS/Python 구문 및 매니페스트 해시를 검사합니다. 제외 리소스를 넣은 실행용 사본에서는 의도적으로 실패합니다.

- 생성한 폰트와 상세 출력 자료는 공개 저장소에 올리지 마세요. 도구는 원본 실행파일을 실행하거나 내려받지 않습니다.
